# Patiensklubben

Patiens för mobil, surfplatta och dator, gjord för att vara lugn och tydlig.

**Spela:** https://danielnilssonit.github.io/patiensklubben/

- **Fem patienser:** Harpan (Klondike, dra 1 eller 3), Spindelharpan (en, två eller fyra färger), FreeCell (Microsofts givar 1–32 000), Pyramiden och Tre toppar.
- **Givar som går att vinna:** en lösare har räknat fram tusentals givar som garanterat går att vinna. Den som följer tipsen vinner.
- **Stora, tydliga kort** med svenska bokstäver (Kn, D, K, E) eller engelska (J, Q, K, A), fyrfärgslek och tre textstorlekar.
- **Ett tryck flyttar kortet** dit det passar. Korten kan också dras. Ångra hur mycket som helst. Tips som läses upp.
- **Dagens patiens:** samma giv för alla varje dag.
- **Lugnt och tydligt:** lugnare tempo, större text, ingen klocka och lätta givar.
- Patiensen sparas hela tiden. På iPhone och iPad: *Dela → Lägg till på hemskärmen*, så startar den som en app och fungerar utan internet.

Kortbilderna är ritade i koden (SVG). Musiken är gjord med Suno och rösten med ElevenLabs. Startbilden är renderad i Blender.
Den här mappen byggs automatiskt (tools/build-pages.mjs i projektet).
